## 🚀 Featured Projects

### 🛒 [Olist E-commerce Business Performance Analysis](https://github.com/KYogeshPandey/olist-ecommerce-sql-analysis)

End-to-end **SQL business analytics project** built on the Brazilian Olist marketplace dataset to analyze revenue, customers, products, sellers, delivery performance and customer reviews.

**Key Highlights**

- Advanced SQL analysis using **Joins, CTEs, Subqueries and Window Functions**
- Customer **RFM segmentation and repeat-purchase analysis**
- Revenue, product, seller, delivery and review performance analysis
- Data-quality validation and reusable analytical views
- Structured **40 analytical SQL queries**
- Power BI-ready analytical handoff

**Tech Stack**

`MySQL` `SQL` `CTEs` `Window Functions` `RFM Analysis` `Data Cleaning` `Business Analysis`

➡️ **[View Project](https://github.com/KYogeshPandey/olist-ecommerce-sql-analysis)**

### 📊 [Mobile Sales Dashboard – Power BI](https://github.com/KYogeshPandey/mobile-sales-dashboard-power-bi)

Interactive **Power BI sales analytics dashboard** built to analyze mobile sales performance across brands, models, cities, payment methods, customer ratings and time periods.

**Key Highlights**

- Analyzed **3,835 transactions**
- Analyzed **₹769M+ total sales**
- Created reusable **DAX KPI measures**
- Built interactive slicers and drillable business views
- Performed brand, model, geographic and time-based sales analysis
- Converted transactional data into actionable business insights

**Tech Stack**

`Power BI` `DAX` `Microsoft Excel` `Data Modeling` `KPI Reporting` `Data Visualization`

➡️ **[View Project](https://github.com/KYogeshPandey/mobile-sales-dashboard-power-bi)**
